## 🚀 Featured Projects

### 🚚 Mini TMS — BIEN TRANS

**Transport Management System for a small family transport business**

A Django-based internal business application designed around real transport operations and daily workflow requirements.

**Key features:**

* Transport booking management
* Admin / Driver role-based access
* Driver assignment and transport status workflow
* Trip sheets and route stops
* Transport document tracking
* CMR PDF generation
* Income and expense management
* Operational and financial reports
* CSV / XLSX export
* PostgreSQL and Docker support
* Automated regression testing

**Tech:** `Python` `Django` `PostgreSQL` `Docker` `Bootstrap` `JavaScript` `WeasyPrint` `openpyxl`

> The production source code and company data are private.
> A public case study is available with architecture, business workflows, technical decisions and implemented functionality.
